# K-EMBANK 웹 디자인 기준 (보관 문서)

> 이 문서는 이전 화면별 메모를 보존한 것이다. 새 화면 설계에는 루트 `design.md`와 `design/`의 현재 규칙을 사용한다.

## 목적

GeoSettle, 연직배수공, 표층처리공, 재하성토공을 하나의 설계 작업 공간처럼 보이게 한다. 시각적 변경은 계산식, 수량, 원본 DXF 좌표, 저장 형식을 바꾸지 않는다.

## 화면 구성

- 메인: 기본 `전체` 보기에서 현재 세 도구를 같은 크기의 그림 카드로 보여준다. `구조계산`, `수량산출`, `주요 설계인자` 분야 선택으로 도구를 거를 수 있으며 새 도구는 해당 분야의 카드로 추가한다. 카드 전체가 각 기능의 상대 경로 링크다. 하단에는 현재 연결된 `GeoSettle 설계 → 구역 연결 → 공종별 수량산출` 흐름을 둔다. 앞으로 모든 구조계산 도구가 같은 흐름에 연결된다고 가정하지 않는다.
- 기능 화면: 제목과 현재 상태를 먼저 보여주고, 주요 실행 버튼을 구분한다. 입력 → 구역 확인 → 계산 → 결과·3D 순서를 따른다.
- 재하성토공과 연직배수공의 상단은 `shared/tool-page-header.css`를 공통으로 사용한다. 제목·설명·상태 배지, 실행/내보내기/저장 툴바, 파일 가져오기 버튼의 높이·간격·테두리·글자 크기를 맞춘다. 공종별 기능 차이는 버튼 구성과 이름에만 반영한다. 연직배수공은 입력 변경 즉시 수량을 갱신하므로 상단 주요 동작을 `수량산출서 Excel`로 표시하고, 재하성토공은 `수량 계산`으로 표시한다.
- 기능 화면 사이드바: 재하성토공과 연직배수공은 같은 도구 전환 컴포넌트를 쓴다. 브랜드 아래 `← 메인페이지`는 테두리 없는 상단 이동 링크로 둔다. 현재 화면의 내부 메뉴는 그다음에 배치한다. 다른 도구로 이동하는 링크는 하단 구분선 아래 `다른 도구` 묶음으로 배치하고, 도구명과 오른쪽 화살표로 표시한다. 링크에 `열기`를 반복하지 않는다.
- 재하성토 평면도: DXF 경계와 항공사진의 표시 상태를 명확히 구분한다. 항공사진이 없어도 DXF 평면도를 사용할 수 있다.
  - 입력 관리 첫 화면은 평면도와 자료 가져오기를 나란히 배치한다. 현장 영상이 세로로 긴 경우에도 평면도 카드의 가로 폭을 제한해 이미지가 작은 섬처럼 보이지 않게 한다. 화면이 좁으면 두 카드를 세로로 쌓는다.
- 연직배수공 도면 입력: 재하성토공과 같은 좌측 평면도·우측 자료 가져오기 카드 구성을 쓴다. DXF를 올리기 전에도 빈 평면도와 안내 문구를 표시한다. DXF와 GeoSettle 프로젝트 JSON 업로드, 자동 매칭, 선택 영역 배정은 오른쪽 카드에서 처리하며 좁은 화면에서는 두 카드를 세로로 쌓는다. 상단 툴바의 `최신 설계 가져오기`는 GeoSettle에서 전달된 설계를 불러오는 동작으로 유지한다.
- 재하성토 3D: 계산 결과를 만든 뒤에만 메시를 그린다. 사진 배경은 표시 옵션이며 수량·DXF 형상에 영향을 주지 않는다.
- 재하성토 집계·제거 조건: 유용 재료는 이름을 입력해 추가하고 태그 형태 목록에서 이름 수정·삭제를 한다. 추가한 각 재료의 물량(㎥) 입력은 다른 계산 조건과 같은 4열 입력 격자에 표시한다. 항목이 없을 때는 물량 입력칸도 표시하지 않는다.
- 표층처리공 자료 가져오기: 쇄석매트·배수층 평면 DXF와 GeoSettle 프로젝트 JSON은 평면도 옆 자료 가져오기 카드에 둔다. 파일명과 상태, 교체 동작을 표시한다. 배수층 사면 경사 1:H와 구역별 장비 단계 추가 두께는 표층처리공 입력으로 관리한다. 2D와 3D 결과를 분리한다.
- 재하성토공 자료 가져오기: 재하성토 평면 DXF와 표층처리공 프로젝트 JSON을 평면도 옆에 둔다. 두 공종의 평면은 동일 XY 좌표에서 겹쳐 확인하되 경계·면적 일치를 요구하지 않는다. 배수층이 있는 부분의 재하토는 그 위에, 없는 부분은 원지반 위에 배치한다. 재하성토공의 산출 결과에는 재하토 설치량과 여성제거공의 배수층 제거량을 둔다. 배수층 설치량과 설치 사면 경사는 표층처리공에서 관리한다.

## 읽기와 조작

- 본문과 입력은 가능하면 14px 이상, 표와 보조 설명은 12px 아래로 낮추지 않는다.
- 핵심 수량에는 단위를 함께 표시한다. 재하성토공의 입력·단계별 집계·구역별 산출근거·여성제거공 표는 머리글과 값을 가운데 정렬한다.
- 긴 표는 표 영역 안에서 스크롤한다. 헤더는 고정하고 구역 이름은 왼쪽에 둔다.
- GeoSettle 설계지반정수 엑셀 서식은 압밀층 10행·재하성토 5행을 기본 입력 공간으로 제공한다. 두 표 제목은 왼쪽 정렬하고, 타입·모래층 여부 헤더는 허용값을 줄바꿈해 표시한다. 모래층 여부는 체크박스 대신 O/X로 기록하며 타입과 모래층 여부는 목록에서 선택한다. 빈 행을 건너뛰어 입력해도 가져오기에서 읽는다.
- GeoSettle의 단위중량 기호 γ는 화면 표와 Excel 출력에서 Times New Roman 글꼴로 통일한다. 아래첨자와 단위 텍스트는 기존 서식을 유지한다.
- 버튼은 기본·보조·위험 동작을 구분한다. 계산과 파일 내보내기를 같은 우선순위로 강조하지 않는다.
- 사이드바 이동 링크는 실행 버튼과 구분한다. 평소에는 테두리·채우기를 쓰지 않고, 마우스를 올리거나 키보드 초점을 받을 때 배경 또는 초점 테두리를 표시한다. 두 공종의 링크 간격·글자 크기·모서리·상호작용은 `shared/tool-sidebar.css`에서 공통 관리한다.
- 2D/3D 보기 설정을 바꿀 때 물량 계산을 다시 실행하지 않는다.
- 페이지를 스크롤할 때 포인터가 숫자 입력이나 단계 선택 위에 있어도 값을 변경하지 않는다. 스크롤만으로 계산 결과 또는 3D 모델이 초기화되어서는 안 된다.
- 재하성토 평면은 파란 반투명 면과 실선, 쇄석매트 평면은 호박색 반투명 면과 점선으로 표시한다. 두 표시를 독립적으로 켜고 끌 수 있어 겹친 영역에서도 두 경계를 확인할 수 있다.
- 입력 표의 면적은 재하성토 DXF와 쇄석매트·배수층 DXF를 별도 열로 표시한다. 쇄석매트 도면이 없는 구역은 배수층 면적을 빈 상태로 표시한다. 각 층의 3D 형상과 본체·사면 물량은 표시된 원본 평면별로 산출한다.
- 업로드된 재하성토·쇄석매트 DXF와 GeoSettle JSON 카드에는 동일하게 `교체` 동작을 표시한다.
- 3D에서는 구역마다 색을 달리하고 같은 구역의 배수층은 더 진한 색으로 표시한다. 재하성토와 배수층은 각각 체크박스로 켜고 끄며, 배수층 단독 표시가 가능해야 한다. 구역 선택 정보에는 두 재료의 본체·사면·누적 체적을 각각 보여주고 합계를 별도로 표시한다.
- 3D 보기의 화면 해상도는 캔버스 전체 픽셀 수를 제한하면서 기기 해상도에 맞춘다. 카메라 깊이 범위는 모델 크기와 카메라 거리에 맞춰 갱신해 먼 시점의 경계 깜빡임을 줄인다. 이 표시 조정은 메시 좌표와 수량을 바꾸지 않는다.
- 3D의 `사면부` 단독 보기는 설계 사면 윗면만 표시한다. 숨긴 본체 아래의 바닥면과 절단 옆면을 화면에 드러내지 않는다. 전체 보기와 DXF 출력에는 체적 검증에 필요한 닫힌 메시를 유지한다.
- 수량산출 결과에는 선택 단계의 재하성토와 배수층을 각각 본체·사면·합계로 표시한다. 단계별·구역별 표도 두 재료의 체적을 구분하고 전체 합계를 함께 보여준다.
- 재하성토 결과 카드에는 전체 필요량과 재하토·쇄석매트 필요량을 구분한다. 신규 재하토 반입 NET·ADD는 재하토 필요량에서 유용 재료만 공제해 계산하며, 쇄석매트 체적을 포함하지 않는다. 재하성토공 `2.5.1` 산출서도 같은 결과를 참조한다.
- 키보드 초점, 빈 화면, 로딩, 오류, 재계산 필요 상태를 화면에 표시한다.
- 넓은 화면에서 본문이 잘리지 않도록 `min-width: 0`과 반응형 격자를 사용한다. 좁은 화면은 패널을 세로로 배치한다.

## 항공사진 중첩의 데이터 규칙

1. 원본 DXF의 XY 단위와 좌표계를 확인한다. 단위(m/mm)만으로 EPSG를 추정하지 않는다.
   - 현장 `좌표.dxf`는 사용자가 EPSG:5187 동부좌표계라고 확인했다. 파일 헤더는 mm지만 실제 XY 값은 m이므로, 별도 **좌표 기준 DXF** 가져오기에서만 m로 해석한다. 일반 DXF의 자동 단위 처리는 유지한다.
   - 동일한 구역명이 들어 있는 기존 설계 도면은 기준 도면에 회전·이동으로 정합한다. 형상 오차 0.02 m 이하와 면적 일치를 확인한 뒤 구역 ID·높이·연결 정보를 유지하고 결과를 재계산 필요 상태로 바꾼다. 맞지 않으면 입력을 유지한다.
2. 사용자가 제공하는 항공사진에는 이미지 경계의 실제 좌표 또는 지오리퍼런스 자료가 필요하다. 일반 사진만 있으면 정확한 위치를 주장하지 않는다.
3. 먼저 이미지의 XY 범위에 DXF 구역 경계를 겹친다. 범위·방향·오차를 사용자가 확인할 수 있게 한다.
4. 3D 메시에는 기존 계산 결과의 XY와 표고를 그대로 쓴다. 항공사진은 바닥 시각 자료로만 사용하며 지형 높이로 해석하지 않는다.
5. 온라인 영상은 사용 권한이 있는 WMS 1.1.1 서비스 주소·레이어·DXF와 같은 EPSG를 입력해 현재 구역 범위의 이미지를 요청한다. 브라우저 CORS 허용이 필요하며, 서비스 키와 영상 출처·촬영 시점은 공급자 기준으로 관리한다. DXF 좌표계가 불명확하면 요청하지 않는다.
   - 브이월드 개발키 입력은 별도 WMTS 영상지도 기능에 사용한다. EPSG:5187 구역을 EPSG:3857 타일에 맞춰 재투영한 이미지를 2D 및 3D 보기의 배경으로 공유한다. 키와 영상은 프로젝트 JSON 및 저장 데이터에 포함하지 않는다.
   - 브이월드 영상 요청 범위는 구역을 모두 포함하고 현재 평면도 캔버스의 가로·세로 비율에 맞춘다. 평면도에서는 영상 범위로 화면을 맞춰 여백 없이 표시하며, 영상이나 좌표를 늘이거나 자르지 않는다.
6. 큰 이미지는 표시 크기를 제한하고 화면을 떠날 때 텍스처·GPU 자원을 정리한다. 항공사진을 계산 Worker나 수량 결과에 포함하지 않는다.

## 적용 순서

1. 메인 카드와 공통 색·글자·간격을 정리한다.
2. 재하성토의 제목, 툴바, 표, 2D/3D 배치를 같은 기준으로 맞춘다.
3. 좌표가 확인된 항공사진을 2D 배경으로 표시하고 DXF 구역을 겹친다.
4. 동일한 좌표 범위의 사진을 3D 바닥 평면에 표시하고 기존 메시를 겹친다. 이 평면은 지형 표고가 아니므로 지형 기복이나 사진의 촬영 시점 형상을 재현하지 않는다.
   - 선택형 브이월드 3D 지형 보기는 현재 수량 결과의 성토 메시를 EPSG:5187 위치에 올린다. 지형 높이와 설계 표고의 기준 차이는 표시용 높이 보정값으로 조정하며 계산·DXF 좌표에는 반영하지 않는다. 3D 지도 SDK는 버튼을 누를 때만 로딩하고 돌아가거나 입력이 바뀌면 지도를 정리한다.
5. 다른 도구의 공통 요소를 순차적으로 맞춘다.

디자인 시안 속 항공사진·프로젝트명·수량은 예시이며 실제 현장 자료가 아니다.

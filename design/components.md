# 컴포넌트와 상태

## 공통 부품

| 부품 | 위치 | 규칙 |
| --- | --- | --- |
| 헤더 | 전체 상단 | 제목(SLOPE/W 자동화 도구), 부제(사용 순서), 테마 전환 버튼. 어두운 배경(`--header-bg`). |
| 탭 네비게이션 | 헤더 아래 | 6개 탭: 물성치 입력, Region 매핑, GSZ 편집, 결과 뷰어, 편심 지지력 검토, DXF → GeoStudio. 현재 탭 강조. |
| 파일 설정 섹션 | 각 탭 최상단 | 파일 라벨, 입력 버튼, 파일명 표시, 상태 메시지. `group` 스타일 적용. |
| 메인 작업 영역 | 파일 설정 아래 | 표, 캔버스, 입력 폼. 콘텐츠에 따라 유연하게 배치. |
| 하단 컨트롤 | 콘텐츠 아래 | 진행률 표시, 주 행동 버튼(파란색), 보조 행동들(회색). `bot-row` 스타일. |
| 실행 로그 | 맨 하단 | 계산/실행 결과 메시지. `log-box` 스타일. |

- `styles.css`의 기존 클래스와 CSS 변수를 활용한다.
- 새로운 부품을 추가할 때는 계산이나 자료 스키마를 수정하지 않는다.
- 버튼, 입력, 표의 높이·크기·모서리를 일관되게 유지한다.

## 행동과 피드백

### 버튼과 상태

- 각 탭의 주 행동(▶ 실행, ▶ 계산, ▶ 내보내기 등)은 **파란색 버튼** (`btn-primary`)으로 채운다.
- 보조 행동(JSON, PNG, 다운로드, 복사)은 **회색 버튼** (`btn` 또는 `btn-secondary`)으로 둔다.
- 비활성 버튼에는 비활성 이유를 `<span class="hint">` 또는 `title` 속성으로 표시한다.
- 버튼의 높이·패딩·모서리를 일관되게 유지한다.

### 파일 상태

파일 입력은 다음 상태 중 하나를 가진다:
- `비어 있음`: 파일이 선택되지 않음
- `읽는 중`: 파일을 처리 중 (진행률 표시)
- `유효`: 파일이 로드되고 유효함
- `검증 필요`: 파일은 로드되었으나 데이터 검증 필요
- `오류`: 파일 형식, 좌표계, 또는 데이터 오류

상태는 파일 입력 옆의 `<span class="rv-status">` 또는 색상 인디케이터로 표시한다.

### 계산 및 실행 상태

- `대기`: 입력이 필요하거나 선행 단계 완료 필요
- `진행 중`: 계산 또는 처리 중. 진행률(`progress-bar`)을 표시하고 사용자 입력을 잠금.
- `완료`: 결과가 준비됨. 다음 단계로 진행 가능.
- `재계산 필요`: 입력 변경으로 인해 결과가 오래됨.
- `오류`: 계산 실패. 원인과 해결 방법을 `log-box`에 표시.

상태 메시지는 섹션 타이틀 근처 또는 상단에 표시한다.

### 피드백

- 오류 메시지는 `log-box` 또는 인라인 경고(`<span class="hint">`)로 원인과 다음 행동을 함께 표시한다.
- 진행률은 `<div class="progress"><div class="progress-bar"></div></div>`로 표시한다.
- 성공 메시지는 로그에 기록하고 필요시 토스트로 알린다.
- 캔버스 조작(확대/축소, 드래그)은 표나 입력값을 초기화하지 않는다.

## 입력과 표

### 입력 폼

- 라벨(`<label>`)은 입력 위에 두거나 왼쪽에 배치한다. 필수 입력은 별(★) 또는 명시적 표시.
- 단위, 예시, 허용 범위는 입력 아래 또는 우측의 작은 텍스트(`<span class="hint">`)로 표시.
- 읽기 전용 계산값은 `readonly` 속성의 입력 또는 `<span>` 태그로 표시하고, 계산 근거(파일명, 방법)를 명시.

### 데이터 표

- 표 헤더(`<thead>`)는 밝은 배경(`--surface-muted`)으로, 행과 구분.
- 머리글 세로 정렬(우측 정렬 for 숫자, 좌측 정렬 for 텍스트)과 값을 일관되게 맞춘다.
- 긴 표는 독립적으로 스크롤하고, 헤더 고정 또는 첫 열 고정을 검토.
- 행 높이와 패딩을 일관되게 유지하여 데이터 밀도와 가독성의 균형을 맞춘다.
- Material ID, Region ID, 분석명 등 ID 열은 구분 가능한 색(`--map-id` 등)으로 표시.

### 재료·구역 목록

- 재료나 구역 추가는 `+ 행 추가` 버튼으로 한다.
- 각 항목은 이름, ID, 상태를 표시하고 삭제 버튼을 우측에 둔다.
- 구역은 고유 ID로 연결되고, 화면에서는 자연 정렬(A-1, A-2, A-10, B-1 순).
- 표 행 전체를 클릭하면 캔버스에서 강조 표시할 수 있도록 상호 작용 지원.

## 2D 캔버스

- **DXF 도면**: Region 경계, Material 할당, 상재하중 등을 캔버스에 표시.
- **도형 색**: 각 Region/Material에 구분 가능한 색 할당. 할당되지 않은 영역은 점선 테두리로 표시.
- **레이어 토글**: 도면 > 도구모음에서 재료, 하중, 슬립, 노드, 격자 등을 독립적으로 숨김/표시.
- **캔버스 컨트롤**: 
  - 확대/축소: 휠 또는 버튼(`+`, `-`, `1:1`)
  - 이동: 중간 버튼 드래그 또는 Alt+드래그
  - 선택: 클릭하면 표에서도 강조, Esc로 해제
  - 범례: 아래쪽 또는 우측에 색상 범례 표시
- **커서와 피드백**: 도구 모드(재료, 하중, 슬립 등)를 표시하고, 선택 가능한 요소 위에서 커서 변화.
- **조작법**: 캔버스 아래 또는 상단에 간단한 도움말 표시 (예: "휠: 확대/축소 · 중간 버튼: 이동").

### 결과 캔버스 (결과 뷰어)

- **지반**: 리즌을 물성치 색으로 채운다.
- **파괴원호**: 임계 슬립면을 곡선으로 그리고 FOS를 표시. 스타일(선 두께, 색, 텍스트 위치) 커스터마이징 가능.
- **상재하중**: 하중 작용 구간에 화살촉 표시. 화살촉 밀도와 크기 조정 가능.
- **수위선**: 지하수위를 대시 라인으로 표시.
- **캔버스 설정**: 결과 뷰어 상단에서 이미지 크기, 색상, 스타일 변경 가능.

## 접근성과 반응형

### 접근성

- **버튼과 링크**: 모든 제어에 보이는 이름을 붙인다 (`aria-label`, 텍스트 라벨).
- **탭**: `role="tablist"`, `role="tab"`, `aria-selected` 사용. 탭으로 전환하고 탭 키로 탐색 가능.
- **레이어와 체크박스**: `aria-checked`, 가시적 체크 표시로 상태 명확하게.
- **표**: `<thead>`, `<tbody>`, 헤더 정보(`<th>`), 행·열 범위(필요시).
- **입력**: `<label for="id">` 명시적 연결, `required` 속성, 오류 메시지는 `role="alert"`.
- **이미지와 캔버스**: `alt` 텍스트 또는 `aria-label` 제공.
- **초점 표시**: `:focus` 스타일 제거하지 않음. 충분한 대비와 가시성 유지.

### 반응형

- **데스크톱 (≥900px)**: 2열 레이아웃 (도면 + 표, 또는 상단 메뉴 + 본문).
- **태블릿 (600~900px)**: 1열로 전환. 캔버스와 표를 세로 배열.
- **모바일 (<600px)**: 모든 섹션을 세로 배열. 표는 최소 너비 유지하며 가로 스크롤 가능.
- **표**: `min-width: 0`, 긴 표만 독립 스크롤. 전체 페이지 가로 스크롤 방지.
- **캔버스**: 컨테이너 너비에 맞춰 반응형 렌더링.
- **버튼**: 터치 대상 크기 최소 44px × 44px.
- **기능 숨김 금지**: 기능을 숨기는 대신 우선순위대로 래핑하고 스크롤 가능하게 구현.

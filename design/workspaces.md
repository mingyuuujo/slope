# 공종 적용 지도

이 문서는 계산 명세가 아니다. 공통 화면에서 각 공종에 필요한 입력과 결과의 위치를 정의한다.

| 화면 | 자료 가져오기 | 주 행동 | 분석·결과 | 현재 상태 |
| --- | --- | --- | --- | --- |
| GeoSettle | 설계 입력·프로젝트 JSON | 설계 계산 | 입력, 해석, 단계·차트 결과 | 자체 화면 구조 |
| 표층처리공 | 배수층 DXF, GeoSettle JSON, 매트·장비 입력 | 수량 계산 | 2D/3D 기준, 단계·구역 결과, 배수층 모델 | 공통 헤더, 탐색 보완 필요 |
| 재하성토공 | 재하성토 DXF, 표층처리 프로젝트 JSON | 수량 계산 | 2D/3D 기준, 단계·구역 결과, 재하토 모델·제거량 | 공통 헤더·탐색 |
| 연직배수공 | 구역 DXF, GeoSettle JSON | 수량산출서 Excel | 구역·공법 입력, 산출근거, Excel | 공통 헤더·탐색, 내부 메뉴 보완 필요 |

## 공통 순서

1. **프로젝트와 자료**: 입력 파일, 좌표계·단위, 연결 프로젝트를 확인한다.
2. **구역과 조건**: 구역별 값, 장비·재료·단계, 적용 조건을 편집한다.
3. **계산과 검토**: 산출 기준과 최신 상태를 확인한다. 요약에서 구역별 근거로 내려간다.
4. **공간 검토**: 2D/3D에서 같은 구역의 층·단계·경계를 확인한다.
5. **산출서와 저장**: 같은 계산 결과로 Excel을 만들고 JSON 백업·브라우저 저장을 한다.

## 허용할 차이

- GeoSettle은 설계 입력과 해석 결과가 중심이다. 수량 화면의 DXF 카드나 2D/3D 탭을 억지로 넣지 않는다. 탐색·상태·표의 시각 언어부터 맞춘다.
- 표층처리공은 매트와 배수층 설치량, 배수층 사면 경사, 구역별 장비 두께를 소유한다. 2D와 3D 결과를 각각 표시한다.
- 재하성토공은 배수층 또는 원지반 위의 재하토 설치량을 산출하고 기존 업무 규칙상 여성제거공의 배수층 제거량을 표시한다. 배수층 설치량을 재하토 필요량에 더하지 않는다.
- 연직배수공은 입력 변경 즉시 수량을 갱신한다. 주 행동은 계산 버튼 대신 Excel일 수 있다.
- 프로젝트에 없는 재료·장비·공종은 빈 고정 섹션으로 남기지 않는다.

## 현재 확인한 차이

- 표층처리공 사이드바에는 공종 전환 영역이 빠져 있고 재하성토공과 메뉴 구성이 다르다.
- 연직배수공의 페이지 내부 섹션 탐색은 다른 수량 도구와 다르다.
- GeoSettle은 별도의 헤더·탭·표 스타일을 갖는다. 계산 흐름이 달라 마크업 일괄 교체 대상이 아니다.
- 공종별 CSS에 카드·표·버튼 재정의가 많다. 공통 토큰을 적용할 때 화면별 차이를 확인하면서 줄인다.

# 기본 원칙과 화면 구조

## 정보 구조

```text
SLOPE/W 자동화 도구
├─ 헤더 (제목, 설명, 버튼)
├─ 탭 네비게이션 (6개 단계)
└─ 탭 콘텐츠
   ├─ 파일 설정 (입력 파일, 출력 파일명)
   ├─ 메인 작업 영역 (표, 캔버스, 입력 폼)
   ├─ 진행 상태 표시
   └─ 실행 로그
```

- 헤더에는 제목, 간단한 설명, 사용 순서를 표시한다.
- 상단 탭은 5개 주요 단계와 1개 부가 탭(편심 지지력 검토)으로 구성된다. 각 탭은 독립적인 작업 흐름을 나타낸다.
- 각 탭 내에서 파일 설정은 최상단에, 메인 작업 영역(표, 캔버스)은 중앙에, 실행 결과와 로그는 하단에 둔다.
- 파일 상태(로드 중, 유효, 오류)와 계산 상태(대기, 진행 중, 완료, 오류)를 실시간으로 표시한다.
- 긴 표는 독립적으로 스크롤하고, 캔버스는 확대/축소와 드래그 조작을 지원한다.
- 주 행동(▶ 실행)은 파란 버튼, 보조 행동(다운로드, 복사, JSON)은 회색 버튼으로 구분한다.

## 레이아웃

| 영역 | 기준 |
| --- | --- |
| 헤더 | 제목, 부제(사용 순서), 테마 전환 버튼. 데스크톱과 모바일 동일. |
| 탭 네비게이션 | 6개 탭을 가로 배열. 스크롤 가능하게 구현. |
| 콘텐츠 영역 | 전체 너비 사용. 섹션별로 수직 배열. |
| 파일 설정 | 라벨, 입력, 상태 메시지를 같은 행에 배치. |
| 메인 작업 | 표/캔버스 영역은 사용 가능한 공간을 최대 활용. `max-width` 제한 없음. |
| 제어판 | 캔버스 아래 또는 우측에 배치. 데스크톱에서는 우측 사이드바, 좁은 화면에서 아래. |
| 하단 | 진행률 표시, 주 행동 버튼, 보조 행동들. 버튼을 `row` 또는 `wrap`으로 배열. |

긴 표는 스크롤 가능하게 구현. 가능한 경우 머리글을 고정한다. 페이지 전체 가로 스크롤은 피한다. 창 크기 변경이나 스크롤로 입력값과 계산 결과가 바뀌면 안 된다.

## 시각 토큰

현재 SLOPE/W 자동화 도구는 다크 테마와 라이트 테마를 지원한다. 아래는 **목표 설계 토큰**이며, `styles.css`의 변수명과 점진적으로 정렬할 계획이다.

### 라이트 테마 매핑

| 설계 토큰 | 현재 변수 | 용도 |
| --- | --- | --- |
| `--ui-canvas` | `--bg` / `#eef0f5` | 작업 배경 |
| `--ui-surface` | `--surface` / `#ffffff` | 카드·표 |
| `--ui-surface-muted` | `--surface2` / `#f3f5fa` | 표 머리글·보조 영역 |
| `--ui-ink` | `--text` / `#1a1f2e` | 본문·제목 |
| `--ui-ink-muted` | `--muted` / `#5a6478` | 설명·메타데이터 |
| `--ui-brand` | `--accent` / `#2563eb` | 주 행동·선택·초점 |
| `--ui-line` | `--border` / `#c8cedb` | 경계 |

### 다크 테마 매핑

| 설계 토큰 | 현재 변수 | 용도 |
| --- | --- | --- |
| `--ui-canvas` | `--bg` / `#1a1d23` | 작업 배경 |
| `--ui-surface` | `--surface` / `#1e2130` | 카드·표 |
| `--ui-surface-muted` | `--surface2` / `#252838` | 표 머리글·보조 영역 |
| `--ui-ink` | `--text` / `#e8eaf0` | 본문·제목 |
| `--ui-ink-muted` | `--muted` / `#8b90a8` | 설명·메타데이터 |
| `--ui-brand` | `--accent` / `#2e6fdb` | 주 행동·선택·초점 |
| `--ui-line` | `--border` / `#2d3142` | 경계 |

- 성공·주의·오류는 `--success`, `--warning`, `--error` 등 의미 색을 쓰되, 아이콘과 문구를 함께 표시한다.
- 캔버스의 2D 영역과 DXF 요소는 구분 가능한 색상으로 표시한다.
- 간격은 8px 계열: 카드 안쪽 16~24px, 섹션 간 24~32px, 요소 간 8~12px.
- 모서리 반지름은 카드 8~10px, 버튼·입력 6px.
- 본문 폰트 14px 이상, 표·메타 12px 이상, 레이블 12px. 모두 명확하고 가독성 있어야 함.
- 글꼴: Pretendard → 맑은 고딕 → sans-serif. 수식(φ, γ) 및 단위 서식 유지.

## 문구와 숫자

- 화면 명칭은 공종명, 산출 기준, 행위를 드러낸다. 예: `재하성토공 → 2D 평면 수량 → 수량 계산`.
- `저장 완료`, `계산 완료`, `최신 설계 연결`, `재계산 필요`, `확인 불가`는 서로 다른 상태다.
- 숫자 열의 자릿수와 단위를 일관되게 표시한다. 빈 값, 0, 적용하지 않음, 자료 누락을 구분한다.
